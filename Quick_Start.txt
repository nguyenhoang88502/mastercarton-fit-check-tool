WAHL Vietnam — Master Carton Fit Tool
======================================

How to launch the tool:
1. Double-click the file "Open_WVN_Master_Carton_Fit_Tool.cmd" in this folder.
2. The launcher will automatically discover the latest weekly BOM and product physical dimension Excel workbooks (e.g. from your OneDrive/SharePoint synced folders).
3. If the tool has been opened on this PC before, a small window asks whether to update the data from the Excel files first
   ("Update data") or open straight away with the data from last time ("Skip"). Updating takes a couple of minutes.
   You can make this automatic in the tool: Settings tab > "Read the Excel workbooks" (once a day, once a week, only when the
   Excel files changed, ...).
4. The tool then opens in Google Chrome or Microsoft Edge.

Good to know:
- "Save this product" and "Save carton" are instant. The entry is written into the Excel dimension workbook the next time the
  data is updated at launch (keep that workbook closed then). The Settings tab shows how many entries are still waiting.
- Every assumption the tool uses (carton wall, growth %, pallet size, stack height, overhang, ...) is on the Settings tab.

Requirements:
- Windows OS
- Built-in PowerShell 5.1
- Google Chrome or Microsoft Edge
- The Excel source files (OneDrive/SharePoint synced)

Troubleshooting:
- If double-clicking the CMD does nothing (window flashes and closes with no
  message), this folder was likely downloaded (email, Teams, chat) and Windows
  is silently blocking it as "from the internet." Fix it with PowerShell:
    Get-ChildItem -Path "<this folder>" -Recurse | Unblock-File
  then try again.
- If the browser does not open, check the newest log file in:
  system/logs/  (each run creates its own file, newest timestamp = latest run)
- If automatic discovery fails, the web tool will allow you to manually select the workbook files.
